# Hand-Drawn Editorial Poster Skill

A flexible hand-drawn editorial poster skill informed by seven example posters. It is **not storefront-only**: it can illustrate architecture, food, everyday objects, and visual metaphors.

## What it does
Input: theme, event information, object, building/storefront photo, or source image.

Process: analyze subject → choose drawing strategy and layout → apply hand-drawn illustration, expressive typography, controlled ink/paper palette and open composition → check legibility and originality.

Output: an original poster, a production prompt, or reference-style analysis, depending on the request.

## Rules at a glance
- Organic, imperfect, but structurally readable line drawings.
- Selective details instead of literal full-scene tracing.
- Expressive title typography paired with readable event details.
- Intentional empty page and paper/ink tactility.
- No prescribed subject, font, exact template, or universally mandatory color.

## Example prompt
> Use hand-drawn-editorial-poster to design a 4:5 poster for a tea pop-up. The main illustration should be a simplified cup and whisk, not a shopfront. Use irregular ink contours, expressive lettering for the short heading, legible supporting type, and visible paper space. Use a limited green-on-cream palette. Do not invent a time or address.

## Originality and attribution
Style references are research examples, not templates to be reproduced. Do not copy reference artwork, store names, addresses or event details. Before redistributing third-party reference images in a public repository, check permission/licensing and add source credits. If permission is unclear, keep private study copies locally and publish your analysis and appropriate links instead.
