## Observed shared traits (fixed visual grammar)
1. Drawn, not photographic: a legible line drawing or marker illustration is the central representational language.
2. Selective depiction: preserve recognizable structural cues, not every surface detail; avoid fully rendered scenes.
3. Human irregularity: variable pressure, imperfect contours, slight wobble, occasional line overlaps or gaps; avoid perfect vector outline.
4. Editorial hierarchy: visually differentiated expressive title, drawing, and compact practical information.
5. Open page: intentional unoccupied background surrounds or separates focal information; avoid wall-to-wall decoration.
6. Print or paper sensibility: subtle scanned-paper, fiber, speckle, grain, or ink irregularity as relevant, not always overt vintage treatment.

## Variable system (not mandatory in every output)
- Subject: storefront, building, street object, food, tool, household object, symbolic scene, or other user concept.
- Drawing complexity: bare contour for a simple object; restrained architectural detailing for facades; selective hatch for texture.
- Layout: title above illustration; illustration enclosing headline; split diagram; object-led stack; oversized type with smaller drawn object.
- Lettering: naive uppercase handwriting, casual lowercase handwriting, expressive cursive, or serif/sans typesetting for clarity.
- Colors: black on warm white; one colored ink on light paper; reversed pale ink on dark flat ground; limited accent hue.
- Material: flat off-white, subtle aged paper, pale yellow, or controlled saturated ink-colored ground.

## Traits belonging only to examples (do not copy)
Specific storefronts, signs, store names, event wording, dates, real locations, company logos, illustrations, decorative corner embossing, and exact placements. Storefronts dominate this sample but are not required by the skill.

## Operational defaults (DESIGN PROPOSALS, not measured averages)
- Default canvas: portrait 4:5, user may override.
- Proposed open-area target: 35–60% of the canvas, adaptable to content length; do not treat as a measured statistic of the references.
- Default palette: background cream (#F5F1E8), near-black ink (#252421). Optional alternatives: pale butter (#F3E8AD) / warm red (#CB4B5B); forest green (#276F62) / off-white (#F3F0E7).
- Default ink count: one dominant ink color; optionally one small accent when requested or content calls for it.
- Hierarchy: one strongest title, one drawn focal event, one restrained block of logistical text. Contrast lettering systems; no need for a single mandated typeface.
- Linework: readable at thumbnail size, irregular, controlled detail rather than uniform vector edges.

## Decision rules
- IF the input is a storefront or building photo, THEN retain distinct architectural markers (windows, entrance, canopy, proportions), simplify perspective and remove distracting surroundings.
- IF the input is a single object or food, THEN use an economical iconic illustration with 2–5 defining features rather than forcing a storefront composition.
- IF the requested information is long, THEN use expressive lettering only for a short heading and typeset supporting text in a clear small font.
- IF the subject illustration is detailed, THEN keep typography and paper texture restrained; IF drawing is extremely simple, THEN let title scale or lettering carry more character.
- IF the background is dark, THEN choose light ink with legible stroke weight and reduce texture noise.
- IF the user provides a reference photograph as a preservation target, THEN maintain defining real-world features; distinguish this from style references.

## Avoid list / failure modes
- Identical storefront drawing in every image; fixed compositional template.
- Smooth CAD/vector outlines, perfect symmetry, photorealistic render, 3D mockup, gradient gloss, fake depth/shadows.
- Pseudo-handwriting that is illegible for event information; copied source identity or existing names.
- Excessive grunge, coffee stains, torn edges, retro ornaments, embossing added to every design.
- Random doodles unrelated to subject, decorative noise, forced second color.

## Confidence and limits
Seven samples establish a convincing hand-drawn editorial family, not a unique typeface, precise numerical blank-space standard, mandatory aspect ratio, or universal illustration technique. The material and composition varies substantially. Initial defaults should be tested with new subjects before being locked down.
